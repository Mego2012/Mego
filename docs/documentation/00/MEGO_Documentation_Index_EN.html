Purpose and scope

This index lists all 77 official MEGO documents, the Google Drive folder each one lives in, its purpose and its intended audience. Every document exists twice: an English version (file name ending in _EN) and an Arabic version (ending in _AR) with the same content. A local HTML copy of each is kept in the repository under docs/documentation/<folder-number>/.

1. How the documentation is organised

  • Location: Google Drive folder "MEGO – Official Documentation", split into 13 numbered sub-folders (00–12).
  • Naming: MEGO_<Topic>_EN and MEGO_<Topic>_AR. Cross-references always use the base file name (without the language suffix).
  • Document IDs: MEGO-DOC-01 … MEGO-DOC-77.
  • Standard structure: title and metadata table, purpose and scope, table of contents, numbered sections, verification status, revision history.
  • Status values: "Approved for internal use", "Draft – requires owner approval", "Draft – requires legal review".
  • Source of truth: every statement is checked against the repository (Mego2012/Mego, branch claude/nutrition-tracking-app-989rku) or the verified live status of 7 November 2026; anything that could not be checked is marked "Not verified".
