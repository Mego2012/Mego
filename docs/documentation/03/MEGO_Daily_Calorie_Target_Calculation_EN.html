Purpose and scope

This document describes how MEGO arrives at the calorie target shown for a day: the saved training/rest targets, the goal recommendation (BMR → TDEE → goal adjustment), the per-date override, the smart cardio/extra-workout adjustment and the fat-loss ceiling. Sources: src/lib/goals.ts, src/lib/targets.ts, src/lib/energy.ts, src/lib/cardio.ts, src/lib/goalAdvisor.ts, src/lib/defaults.ts, src/pages/Settings.tsx, src/pages/Dashboard.tsx. All numeric examples were produced by running this code on 10 Nov 2026. The values are estimates for general guidance, not medical advice (see MEGO_Nutrition_Disclaimer).

2. Saved targets and day type

  • Settings store two target sets: training and rest. Shipped defaults: 2,000 kcal, protein 160 g, carbs 200 g, fat 62 g for both.
  • Training weekdays default to Saturday–Thursday (Friday rest). A day's type can also be changed on that day in the Diary.
  • A per-date override (Diary → day targets) replaces both for that date; "Use default" removes it.

3.2 Worked example — the BMR floor

Female, 35 y, 160 cm, 50 kg, sedentary, fat_loss: BMR = 500 + 1000 − 175 − 161 = 1164; TDEE = round(1164 × 1.2) = 1397; 1397 × 0.8 = 1117.6 → 1120, which is below BMR, so the recommendation is 1,164 kcal (P 90 g, F 40 g, C 111 g; −0.21 kg/week).

4. Applying a recommendation

  • Settings → Profile shows the recommendation live (kcal and P/C/F, BMR, TDEE, protein g/kg, expected weekly change).
  • If the saved training target differs (kcal by more than 10, or any macro by more than 2 g), a note "targets differ" and an Apply recommendation button appear. Applying asks for confirmation and then writes the same values to both training and rest targets.
  • Saving the profile alone never changes targets. During registration the recommended values are pre-filled as editable starting targets.

5. Smart cardio and extra-workout adjustment

Implemented in energyFor(); full rationale in MEGO_Cardio_and_Calorie_Adjustment. Mode "smart" is the default; "off" never adds anything. The result is used for the Home dial and remaining calories only; saved targets are never modified.

1. Session energy (cardio.ts):  gross = MET × kg × h,   net = (MET − 1) × kg × h
2. Planned weekly minutes = cardio sessions/week × minutes/session  (default 6 × 10 = 60; 0 if activity = sedentary)
3. Minutes of the 6 previous days use up the plan first; today's sessions (by time) use what is left;
   only the uncovered minutes count:  extraNet += session net × uncovered min ÷ session min
4. Extra resistance sessions (completed workouts in the last 7 days beyond the planned number/week):
   extraNet += (3.5 − 1) × kg × workout hours
5. replenish % = user setting, else 50 % (fat_loss, fat_loss_preserve, recomp, custom),
                 75 % (maintain, healthy), 100 % (lean_bulk, bulk, performance)
6. allowed = min(400, round(extraNet × replenish% ÷ 10) × 10)
7. fat-loss goals: ceiling check (section 6)
8. adjusted target = base + allowed ;  remaining = adjusted − consumed

5.1 Worked examples (72 kg, activity "active", plan 60 min/week)

Saved routine: treadmill 10 min, 3.5 km/h, 13 % incline → ACSM walking MET = (0.1×58.33 + 1.8×58.33×0.13 + 3.5) ÷ 3.5 = 6.57 → gross 79 kcal, net 67 kcal per session. Five routine sessions on the previous days (50 min) + today's routine (10 min) = 60 min.

6. Fat-loss ceiling

For fat_loss, fat_loss_preserve and recomp, exercise can never move the day to maintenance or surplus:

ceiling = floor(0.9 × (TDEE + extraNet) ÷ 10) × 10
if base + allowed > ceiling:  allowed = max(0, ceiling − base)

Example: same 45-minute extra walk (extraNet 244), but a hand-set base of 2,900 kcal: ceiling = floor(0.9 × (2860 + 244) ÷ 10) × 10 = floor(279.36) × 10 = 2,790. 2,900 + 120 > 2,790 → allowed = max(0, 2,790 − 2,900) = 0; adjusted stays 2,900 (the ceiling never lowers the base).

Sedentary example: TDEE = round(1658 × 1.2) = 1,990; nothing is planned, so a 30-min session with net 160 kcal is all extra → 50 % = 80. Ceiling = floor(0.9 × 2,150 ÷ 10) × 10 = 1,930; base 2,000 + 80 > 1,930 → allowed 0.

7. Goals advisor suggestions

goalAdvisor.ts reviews trends (7-day weight averages, 28-day regression, 14-day adherence, waist change, weekly check-in) and may suggest a calorie change (typically ±150 kcal, ±100 kcal for maintenance drift or fast gain) or a protein target. Suggestions are never applied automatically; when the user approves one, it is applied to both day types (carbohydrates absorb the kcal change: carbs ± delta ÷ 4). For loss goals an increase is limited so the training target stays ≤ round(0.9 × TDEE at the current average weight); if less than 50 kcal of room remains the suggestion becomes "no surplus" without an action.
