الغرض والنطاق

يشرح هذا الدليل كيف يُثبَّت خادم Google Apps Script الخاص بالمالك وكيف يُحدَّث. هذا الخادم (apps-script/Code.gs، الإصدار SCRIPT_VERSION 8) يربط التطبيق بجدول Google ‏«MEGO Nutrition Hub»، وهو المكوّن الوحيد الذي يتواصل مع Gemini API. الطريقة الآلية هي scripts/laptop-setup.mjs؛ ويقدّم الدليل خطوات Windows PowerShell نقرةً بنقرة لمالك غير متخصص، وشاشات Google التي يوافق عليها، وما يفحصه السكربت، وكيفية تحديث الخادم بالخيار --update-backend وإكمال قائمة أطعمة الـ Hub بالخيار --hub-complete-foods.

2. Windows: تجهيز اللابتوب (مرة واحدة)

  1. اضغط زر ابدأ (Start)، واكتب PowerShell، وافتح Windows PowerShell.
  2. ثبّت Git وNode.js (اكتب كل سطر ثم Enter، ووافق على أي سؤال): 
    winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
  3. أغلق PowerShell ثم افتحه من جديد حتى يتعرف على البرامج الجديدة. للتحقق: يجب أن يطبع كل من git --version وnode -v رقم إصدار.
  4. إذا ظهرت رسالة «running scripts is disabled on this system» فنفّذ مرة واحدة: 
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  5. نزّل المشروع إلى مجلد المستخدم: 
    cd $HOME
git clone -b claude/nutrition-tracking-app-989rku https://github.com/Mego2012/Mego.git
cd Mego

مهم: أثناء عمل السكربت لا تنقر داخل نافذة PowerShell. في وضع QuickEdit يؤدي النقر إلى إيقاف البرنامج مؤقتًا فيبدو متجمّدًا؛ اضغط Enter أو Esc للمتابعة.

3. Windows: تشغيل الإعداد

cd $HOME\Mego
node scripts/laptop-setup.mjs

يطبع السكربت كل خطوة بالرمز ▶ وكل فحص بالرمز ✅ أو ❌. وعندما يحتاجك يعرض «👉» مع تعليمة وينتظر Enter. أبقِ حسابك في Google مفتوحًا في المتصفح. إعادة التشغيل آمنة: يُعاد استخدام المشروع والنشر والرمز الموجودة.

5. ما يفعله السكربت وما يفحصه

  1. الرفع: ينسخ Code.gs وappsscript.json إلى المشروع الخاص. في التثبيت الأول يكتب في نسختك الخاصة فقط بصمة SHA-256 لسرّ عشوائي يُستخدم مرة واحدة (BOOTSTRAP_HASH)؛ والسرّ نفسه لا يغادر اللابتوب.
  2. النشر: ينشئ نشر تطبيق الويب (والتشغيلات اللاحقة تحدّث معرّف النشر نفسه).
  3. التثبيت لمرة واحدة (bootstrap): يشغّل installMego() — نسخة احتياطية في Drive، وتحويل Excel إلى Google Sheet أصلي، والتحقق من جميع الأطعمة، والترحيل إلى التبويبات المنظمة. ثم يعطّل نفسه (BOOTSTRAP_DONE) ويعيد رمز التطبيق الذي يُحفظ فقط في ~/.mego-backend/state.json.
  4. الاختبارات الحية (10): قبول الرمز؛ هوية الـ Hub هي ملف Excel الأصلي؛ الـ Hub أصلي وقابل للكتابة؛ تحقق installMego؛ رفض الرمز الخاطئ؛ Food_Database يحتوي كل الأطعمة بقيم مقروءة؛ الكتابة من الهاتف إلى الـ Hub (سجل اختباري)؛ القراءة من الـ Hub إلى الهاتف؛ النسخة الأقدم لا تستبدل الأحدث أبدًا؛ حذف السجل الاختباري حذفًا ناعمًا إلى Deleted_Records.
  5. Gemini (اختياري): يحفظ مفتاحًا مجانيًا ويجري تحليل صورة حقيقيًا واحدًا.
  6. ربط التطبيق: يطبع رمز QR ورابطًا يربطان التطبيق على الهاتف. احتفظ به سرًّا لأنه يحتوي الرمز. لإعادة طباعته: node scripts/laptop-setup.mjs --test.
  7. التقرير: يُكتب في ~/.mego-backend/report-<time>.md.

النتيجة الحية لتشغيل المالك (7 نوفمبر 2026): جميع الفحوص ✅؛ الـ Hub ‏«MEGO Nutrition Hub» يحتوي 160 طعامًا دون أي مشكلة رقمية؛ ونسخة احتياطية باسم «BACKUP MEGO Nutrition Hub — before migrateHub — 2026-11-07 1425».

6. تحديث الخادم (‎--update-backend)

عند صدور Code.gs جديد (مثل الإصدار SCRIPT_VERSION 7 بمعالجة أخطاء الذكاء الاصطناعي المحسّنة، أو SCRIPT_VERSION 8 بالإجراء fillFoodNames) نفّذ في PowerShell:

cd $HOME\Mego
git pull
node scripts/laptop-setup.mjs --update-backend

ما يحدث: يُرفع أحدث Code.gs ويُنشر على النشر نفسه (رابط تطبيق الويب نفسه والرمز نفسه، وبيانات الـ Hub دون مساس)، ثم يرسل تشخيص الذكاء الاصطناعي (aiDiag) طلبًا نصيًّا صغيرًا إلى كل نموذج مجاني ويطبع لكل منها ✅/❌ ورمز HTTP ورسالة Google، إضافة إلى إصدار الخادم والنموذج المضبوط. لا تُشغَّل الاختبارات الحية في هذا الوضع؛ شغّل بعده node scripts/laptop-setup.mjs --test إن أردتها.

7. خيارات أخرى وصيانة

الأمر / الدالةالاستخدام
--hub-complete-foodsيتضمن --update-backend (يرفع أحدث Code.gs وينشره على النشر نفسه)، ثم يشترط خادمًا بالإصدار 8 أو أحدث وجدول Food_Database المنظّم. وهو يضيف فقط: كل مكوّن من مكتبة الوصفات غير موجود في الـ Hub (بقيم USDA مراجعة يدويًا من public/fooddb/library-recipes.json؛ والمكوّن الذي لا مرجع موثّق له يُذكر في القائمة ولا يُقدَّر أبدًا)، وكل وجبة من المكتبة كطعام جاهز محسوب من قيم الـ Hub نفسه (لكل 100 غ من المكونات النيئة، والحصة = وجبة واحدة؛ وتُتخطّى الوجبة إذا كان أحد مكوناتها بلا قيم صالحة)، ويملأ الأسماء الإنجليزية الفارغة فقط (public/fooddb/food-names.json). لا تتغير أي صفوف أو قيم موجودة؛ تُؤخذ نسخة احتياطية يومية للـ Hub في Drive أولًا؛ وإعادة التشغيل لا تضيف شيئًا. لا يُشغَّل تشخيص الذكاء الاصطناعي في هذا الوضع
--testالاختبارات الحية فقط على الخادم الحالي (مع خطوة Gemini ورابط الربط)
--autoدون أسئلة لوحة المفاتيح؛ ينتظر بإعادة الفحص كل 10 ثوانٍ
--photo meal.jpgاستخدام صورتك الخاصة لاختبار الذكاء الاصطناعي
rotateToken() (في المحرر)ينشئ رمز تطبيق جديدًا ويجب ربط التطبيق من جديد. يُوصى به لأن رابط الاتصال ظهر في محادثة أثناء الإعداد
cleanupAiCounters()يحذف عدّادات استخدام الذكاء الاصطناعي الأقدم من 8 أيام (مشغّل زمني اختياري)
البديل اليدويالصق Code.gs وappsscript.json في المحرر ثم Deploy ← Manage deployments ← Edit ← New version (docs/SETUP.md وdocs/PHONE-SETUP.md)

أخطاء الشبكة عند الاتصال بالخادم يُعاد المحاولة فيها 4 مرات (بعد 3 و6 و9 و12 ثانية)، ثم تُعرض رسالة الخطأ الحقيقية من Google.

8. حالة التحقق

البندالحالة
الإعداد الكامل والاختبارات الحيةمُتحقَّق منها حيًّا على لابتوب Windows الخاص بالمالك (7 نوفمبر 2026)؛ والسكربت مُختبر آليًّا بالأمر npm run e2e:laptop ‏(10/10 مع Google محاكى)
