الغرض والنطاق

يشرح هذا الدليل كيف تنقل الشيفرة المصدرية لتطبيق MEGO إلى جهاز كمبيوتر، وتثبّت الاعتماديات (Dependencies)، وتشغّل التطبيق محليًا، وتبنيه، وتعاين نسخة الإنتاج، وتشغّل جميع مجموعات الاختبارات الآلية بما فيها تلك التي تعتمد على محاكيات Firebase ‏(Firebase Emulators). ويتضمن ملاحظات عملية لنظام Windows مستخلصة من تشغيل المالك الفعلي على اللابتوب في 7 نوفمبر 2026. أما إعداد الخدمات السحابية (Firebase وApps Script وGemini) فمشروح في الأدلة ذات الصلة. هذه النسخة العربية تقابل النسخة الإنجليزية مع تحديث أعداد الاختبارات وفق حالة 10 نوفمبر 2026.

2. الحصول على الشيفرة

فرع العمل هو claude/nutrition-tracking-app-989rku في المستودع https://github.com/Mego2012/Mego:

git clone -b claude/nutrition-tracking-app-989rku https://github.com/Mego2012/Mego.git
cd Mego

3. تثبيت الاعتماديات

استخدم npm ci (يثبّت الإصدارات الدقيقة من package-lock.json، وهو الأمر نفسه الذي يشغّله CI):

npm ci

تحتاج مجموعات اختبارات المتصفح وأداة التحقق الحي إلى Playwright، وهي ليست اعتمادية للمشروع عن قصد. ثبّتها دون تعديل package.json:

npm install --no-save playwright@1.63.0
npx playwright install chromium

الأمر npm install (المذكور في README.md) يعمل أيضًا لكنه قد يعدّل ملف القفل؛ لذا يُفضَّل npm ci.

6. محاكيات Firebase

الحزمة firebase-tools اعتمادية تطوير، فلا حاجة لتثبيتها عامًّا. يعرّف الملف firebase.json المحاكيات:

المحاكيالمنفذ
المصادقة (Authentication)9099
Firestore8080
واجهة المحاكي (Emulator UI)معطّلة

تشغّل السكربتات المحاكيات وتوقفها تلقائيًا باستخدام المشروع التجريبي demo-mego (لا يتطلب حساب Google):

npx firebase emulators:exec --project demo-mego --only firestore,auth "vitest run --config vitest.rules.config.ts"

لإبقائها تعمل للعمل اليدوي: npx firebase emulators:start --project demo-mego --only firestore,auth.

7. ملاحظات Windows

7.1 تثبيت Git وNode.js عبر winget

winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e

7.2 تحديث مسار البحث (PATH)

بعد التثبيت أغلق نافذة PowerShell وافتح نافذة جديدة حتى يُعثر على git وnode وnpm. تحقّق بالأمرين git --version وnode -v.

7.3 تجمّد PowerShell بسبب وضع QuickEdit

النقر داخل نافذة PowerShell أو الطرفية مع تفعيل وضع QuickEdit يبدأ تحديد نص ويوقف البرنامج الجاري مؤقتًا، فيبدو الإعداد متجمّدًا. اضغط Enter أو Esc للاستئناف، وتجنّب النقر داخل النافذة أثناء عمل السكربت (أو عطّل QuickEdit من خصائص النافذة).

7.4 سياسة التنفيذ (Execution Policy)

إذا رفض PowerShell تشغيل npm أو npx برسالة «running scripts is disabled on this system»، اسمح بالسكربتات المحلية لمستخدمك فقط:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

أو استدعِ npm.cmd / npx.cmd، أو شغّل الأوامر من موجّه الأوامر (Command Prompt).

7.5 تشغيل npx.cmd (تمت معالجته في الشيفرة)

ترفض Node 18.20+ و20.12+ تشغيل npx.cmd أو npm.cmd دون صدفة (Shell) وتعيد الخطأ EINVAL. لذلك يشغّل scripts/laptop-setup.mjs أداة npm المرفقة مع Node مباشرةً عبر node.exe (الإيداع 65f86ad).

7.6 هوية Git

تثبيت Git الجديد لا يحتوي اسم مستخدم ولا بريدًا. يحفظ سكربت الإعداد ملف إعداد Firebase بهوية محايدة (MEGO setup مع عنوان GitHub من نوع noreply)، ثم يتحقق من أن GitHub استلم التغيير فعلًا.

8. الملفات المحلية والحالة الخاصة

  • ~/.mego-backend/ (أو المجلد المحدد في MEGO_BACKEND_DIR): الحالة الخاصة لسكربت الإعداد (معرّف السكربت، رابط تطبيق الويب، الرمز السري) بصلاحية ملف 600 وخارج المستودع. لا تحفظه في Git ولا تشاركه أبدًا.
  • يتجاهلها Git ‏(.gitignore): node_modules، dist، dev-dist، e2e/screens، *.log، tests/private/.
  • بعض اختبارات القيم في اختبارات الوحدة تستخدم ملف أطعمة حقيقيًا خاصًا في tests/private/؛ وبدونه تُتخطّى هذه الاختبارات (docs/TEST-REPORT.md).
