1. منهج القبول

بدأت المجموعة من سيناريوهات القبول الخمسة عشر في وصف المشروع الأصلي (TEST 1 إلى TEST 15)، ثم توسعت مع الإصدارات: أضافت الميزات الجديدة فحوصًا تقود واجهة المستخدم الحقيقية كما يفعل الشخص (النقر، الكتابة، الاختيار من القوائم) وتتحقق مما يراه. تعتمد الفحوص على سمات data-testid الثابتة لا على المواضع المرئية. وتُحفظ لقطات الشاشات الرئيسية في e2e/screens/.

4. قبول التمرير باللمس (scroll-test.mjs)

مجموعة منفصلة تثبت أن سحب الإصبع يمرّر كل شاشة على هواتف بمقاسات Samsung. تستخدم أحداث لمس خامًا عبر بروتوكول أدوات مطوري Chrome ‏(CDP) ‏(touchStart ← touchMove… ← touchEnd)، يحولها Chrome إلى تمرير حقيقي كالإصبع؛ وتثبت صفحة تحكم أولًا أن الطريقة تعمل.

  • المقاسات: Galaxy S23 ‏(360×780)، Galaxy A54 ‏(412×915)، Galaxy S9+‎ ‏(320×658)، كل منها بالعربية (RTL) والإنجليزية (LTR)، مع وكيل مستخدم Chrome لأندرويد.
  • الشاشات: الرئيسية، اليوميات، الوصفات (أربعة تبويبات)، الأطعمة، المخطط، التقدم، العادات، التقريران الأسبوعي والشهري، الإعدادات.
  • وأيضًا: تدفقات النوافذ (فتح وإغلاق النوافذ المتداخلة، Escape/الرجوع) يجب ألا تترك الصفحة مقفلة التمرير أبدًا.
  • النتيجة: 103/103، وكذلك على الرابط الحي.

5. تشغيل المجموعات وقراءة النتائج

npm run build
npm run e2e                                         # local build, 57 checks
E2E_BASE=https://mego2012.github.io/Mego/ npm run e2e   # same checks on the live site
npm run e2e:scroll                                  # 103 touch checks (local)
node e2e/scroll-test.mjs https://mego2012.github.io/Mego/

يتضمن سطر FAIL السطر الأول من الخطأ، وعند الحاجة سبب Playwright (العنصر غير مرئي، خارج منطقة العرض، يعترضه عنصر آخر). اللقطات في e2e/screens/.

6. معايير القبول للإصدار

  • npm run e2e: ‏57/57 على البناء الإنتاجي المحلي.
  • npm run e2e:scroll: ‏103/103.
  • بعد النشر: المجموعتان على الرابط الحي، إضافة إلى scripts/live-verify.mjs (انظر MEGO_Release_Readiness_Checklist).
  • أي إخفاق يوقف الإصدار حتى يُصلَح أو يُوثَّق صراحةً في MEGO_Known_Bugs_and_Limitations.

7. حالة التحقق

  • مختبَر (جهاز محاكى، بناء محلي): ‏57/57 فحصًا في المتصفح و103/103 فحوص لمس — آخر نتائج مسجلة (10 نوفمبر 2026).
  • مُتحقَّق منه مباشرة: ‏44/44 فحصًا على الرابط الحي في 7 نوفمبر 2026 (قبل إضافة فحوص الإصدارين 1.2 و1.3)؛ ‏103/103 فحوص لمس على الرابط الحي؛ صفحات التمارين الـ 54 ‏54/54 على الموقع الحي (10 نوفمبر 2026).
  • غير مُتحقَّق منه: لا يوجد تشغيل مسجَّل للفحوص الـ 57 كاملة على الرابط الحي؛ Gemini وOpen Food Facts محاكيان في هذه المجموعة؛ الكاميرا وعتاد مسح الباركود والتثبيت على الشاشة الرئيسية في هاتف فعلي (انظر MEGO_Android_Device_Testing). لم تُعَد المجموعة أثناء كتابة هذه الوثيقة.
