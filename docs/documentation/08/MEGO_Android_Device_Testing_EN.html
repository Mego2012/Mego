Purpose and scope

MEGO is a Progressive Web App (PWA) designed first for Android phones (Chrome). This document explains what has been tested on emulated Android devices, what can only be tested on a physical phone, and gives the step-by-step real-device checklist from docs/ANDROID-TEST.md with a results column. Status: the formal real-device checklist has NOT been run yet. The owner uses the app daily on an Android phone, opened from the home-screen icon; that everyday use is real-world evidence that installation and daily logging work, but it is not a recorded test and does not replace the checklist.

3. What only a physical phone can prove

  • "Add to Home screen" and opening full-screen from the icon (formally recorded).
  • Camera barcode scanning — the app uses the browser's BarcodeDetector API (src/lib/barcode.ts), which a headless cloud browser cannot exercise; without camera support the barcode can be typed.
  • Taking a meal photo with the real camera for the AI scanner (the AI path itself was verified live on 10 Nov 2026 through the live app UI).
  • Real finger scrolling, system font size and display size settings, rotation.
  • Airplane-mode behaviour on the device and sync recovery afterwards.
  • Password-reset e-mail arriving in a real inbox.

5. Capturing problems

  • For any ❌, take a screenshot and note the step number.
  • Optional console capture: connect the phone by USB, enable Developer options → USB debugging, open chrome://inspect on the laptop and inspect the MEGO tab.
  • Do not send passwords, API keys or connection links with a report.
