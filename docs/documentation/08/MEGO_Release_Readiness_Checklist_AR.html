الغرض والنطاق

تُستخدم هذه القائمة قبل كل إصدار من MEGO وبعده لتقرير ما إذا كان يمكن نشر الإصدار. تسرد البوابات الإلزامية (جودة الكود، الاختبارات الآلية، سلامة البيانات، الأمان، الخادم الخلفي، التوثيق)، وفحوص ما بعد النشر، والاعتماد النهائي. يعرض العمود الأخير حالة الكود الحالي (الإصدار 1.3 مع إكمال قاعدة الأطعمة في 10 نوفمبر 2026). لا يُنشر الإصدار إلا عندما يكون كل بند مانع ✅ أو يقبله المالك صراحةً.

1. طريقة استخدام القائمة

  1. انسخ الجداول إلى ملاحظات الإصدار أو أشّر عليها في نسخة من هذه الوثيقة.
  2. نفّذ البوابات بالترتيب A ← F. فشل أي بند مانع يوقف الإصدار.
  3. النشر تلقائي: الدفع إلى claude/nutrition-tracking-app-989rku (أو main) يشغّل .github/workflows/deploy.yml ← npm ci وnpm test وnpm run build ← GitHub Pages. إذا فشلت الاختبارات أو البناء لا يُنشر شيء.
  4. التراجع (Rollback): انظر MEGO_Update_and_Rollback_Procedures.

المفتاح: ✅ مُنجز/ناجح · ⏳ معلّق · ❌ فاشل · B = مانع لأي إصدار · L = مانع للإطلاق العام فقط.
