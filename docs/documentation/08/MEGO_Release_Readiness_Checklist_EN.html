Purpose and scope

This checklist is used before and after every MEGO release to decide whether the release may go live. It lists the mandatory gates (code quality, automated tests, data safety, security, backend, documentation), the post-deployment checks and the sign-off. The last column shows the status of the current code (release 1.3 plus the food-database completion of 10 November 2026). A release ships only when every blocking item is ✅ or explicitly accepted by the owner.

1. How to use this checklist

  1. Copy the tables into the release notes or tick them in a copy of this document.
  2. Run the gates in order A → F. A failed blocking item stops the release.
  3. Deployment is automatic: a push to claude/nutrition-tracking-app-989rku (or main) runs .github/workflows/deploy.yml → npm ci, npm test, npm run build → GitHub Pages. If tests or build fail, nothing is deployed.
  4. Rollback: see MEGO_Update_and_Rollback_Procedures.

Legend: ✅ done/passing · ⏳ pending · ❌ failing · B = blocking for any release · L = blocking for public launch only.
