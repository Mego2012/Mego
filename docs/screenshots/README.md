# MEGO 1.1 screenshots

Phone viewport (Pixel 7 emulation, 2× density), Arabic (`-ar-`) and English (`-en-`), light and dark themes.
Demo data: a realistic month generated from USDA values (test-only build, `VITE_DEMO=1`); account screens come from
the multi-user test on the Firebase emulators (`SHOTS=1 npm run e2e:multi`). `full/` holds full-page captures used
for the visual audit.
